Introduction to Data Structures

Data Structure ek way hai jis mein hum data ko organize aur store karte hain taake data ko easily access aur manage kiya ja sake.

Why Data Structures?

  • Data ko organize karne ke liye
  • Data ko efficiently access karne ke liye
  • Programs ki performance improve karne ke liye
Example: Array, Linked List, Stack aur Queue common Data Structures hain.

Arrays

Array ek data structure hai jo multiple values ko ek hi variable mein store karta hai.

Example

int numbers[] = {10, 20, 30, 40, 50};

Array mein har element ka ek index hota hai. Pehla index usually 0 hota hai.

Linked List

Linked List nodes ka collection hota hai. Har node mein data aur next node ka address hota hai.

Types of Linked List

  • Singly Linked List
  • Doubly Linked List
  • Circular Linked List
Example: Node → Node → Node → NULL

Stack

Stack ek linear data structure hai jo LIFO principle follow karta hai.

LIFO ka matlab hai: Last In, First Out.

Stack Operations

  • Push
  • Pop
  • Peek
Example: Plates ka stack. Jo plate sab se last mein rakhi jati hai, woh sab se pehle remove hoti hai.

Queue

Queue ek linear data structure hai jo FIFO principle follow karta hai.

FIFO ka matlab hai: First In, First Out.

Queue Operations

  • Enqueue
  • Dequeue
  • Front
Example: Bus ki line mein jo person pehle aata hai, woh pehle bus mein enter karta hai.

Deque

Deque ka full form Double Ended Queue hai.

Is mein insertion aur deletion dono ends se ki ja sakti hai.

Operations

  • Insert from Front
  • Insert from Rear
  • Delete from Front
  • Delete from Rear

Trees

Tree ek non-linear data structure hai jo hierarchical data ko represent karta hai.

Important Terms

  • Root
  • Parent
  • Child
  • Leaf
  • Subtree
Example: Family tree ek real-world example hai.

Binary Search Tree

Binary Search Tree ek binary tree hota hai jisme left side par smaller values aur right side par larger values hoti hain.

Rule: Left < Root < Right

Graph

Graph ek non-linear data structure hai jo vertices aur edges par based hota hai.

Types of Graph

  • Directed Graph
  • Undirected Graph
  • Weighted Graph
  • Unweighted Graph

Searching

Searching ka matlab hai kisi particular element ko data structure mein find karna.

Searching Techniques

  • Linear Search
  • Binary Search
Example: Agar array mein 50 ko find karna ho, to searching algorithm use kiya ja sakta hai.

Sorting

Sorting ka matlab data ko kisi specific order mein arrange karna hai.

Common Sorting Algorithms

  • Bubble Sort
  • Selection Sort
  • Insertion Sort
  • Merge Sort
  • Quick Sort
Example: 50, 20, 40, 10 ko ascending order mein: 10, 20, 40, 50

Time & Space Complexity

Time Complexity

Time Complexity batati hai ke input size increase hone par algorithm ko kitna time lag sakta hai.

Space Complexity

Space Complexity batati hai ke algorithm ko kitni memory ki zaroorat hoti hai.

Common Big-O: O(1), O(n), O(log n), O(n²)
