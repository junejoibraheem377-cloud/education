Introduction to Web Development

Web Development ka matlab websites aur web applications banana hai.

Main Technologies

  • HTML – Website ka structure
  • CSS – Website ka design
  • JavaScript – Website ki functionality
Example: Ek website mein HTML structure banata hai, CSS usko beautiful banata hai aur JavaScript interaction add karta hai.

HTML

HTML ka full form HyperText Markup Language hai.

HTML website ka basic structure banane ke liye use hoti hai.

Basic HTML Example

<h1>Hello World</h1>
<p>My first website</p>

HTML Elements

HTML elements website ke different parts ko define karte hain.

Common Elements

  • <h1> – Heading
  • <p> – Paragraph
  • <a> – Link
  • <img> – Image
  • <button> – Button
  • <div> – Container

HTML Forms

HTML Forms user se information lene ke liye use hoti hain.

Common Form Elements

  • Input
  • Label
  • Select
  • Textarea
  • Button
Example: Login form mein username aur password ke input fields ho sakte hain.

CSS

CSS ka full form Cascading Style Sheets hai.

CSS website ko colors, fonts, spacing aur layout provide karti hai.

Example

h1 {
  color: blue;
}

CSS Selectors

CSS selectors HTML elements ko select karke un par styling apply karte hain.

Common Selectors

  • Element Selector
  • Class Selector
  • ID Selector
  • Universal Selector
Example: .button { color: white; }

Flexbox & Grid

Flexbox aur CSS Grid website ke layout ko arrange karne ke liye use hote hain.

Flexbox

Flexbox elements ko row ya column mein easily arrange karta hai.

Grid

CSS Grid rows aur columns ke form mein layout create karta hai.

Responsive Design

Responsive Design ka matlab website ko mobile, tablet aur computer screens par properly display karna hai.

Example: Media Queries responsive websites banane ke liye commonly use hoti hain.

JavaScript

JavaScript ek programming language hai jo website ko interactive banati hai.

JavaScript se kya kar sakte hain?

  • Button click handle karna
  • Form validation
  • HTML content change karna
  • Calculations karna
  • Dynamic websites banana
Example: Button click karne par message show karna.

DOM

DOM ka full form Document Object Model hai.

JavaScript DOM ke through HTML elements ko access aur change kar sakti hai.

document.getElementById("demo")

JavaScript Events

Events user ke actions hote hain jinhein JavaScript detect kar sakti hai.

Common Events

  • click
  • mouseover
  • keydown
  • submit
  • change

Local Storage

Local Storage browser mein data save karne ke liye use hoti hai.

Browser refresh hone ke baad bhi saved data available reh sakta hai.

localStorage.setItem("name", "Ali");

Git & GitHub

Git ek version control system hai jo code ke changes ko manage karta hai.

GitHub ek online platform hai jahan developers apna code store aur share kar sakte hain.

Common Git Commands

  • git init
  • git add
  • git commit
  • git push

Mini Web Development Project

Course ke end par ek small website project banaya ja sakta hai.

Project Technologies

  • HTML
  • CSS
  • JavaScript
Project Example: Student Management System, Portfolio Website ya simple Education Website.
