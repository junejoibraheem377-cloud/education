Introduction to Boolean Algebra

Boolean Algebra sirf 2 values pe kaam karti hai: 0 aur 1.

Isme 3 basic operations hote hain:

  • OR (+) — dono mein se ek bhi 1 ho to result 1
  • AND (·) — dono 1 hon tabhi result 1
  • NOT (') — value ko ulta karta hai (0→1, 1→0)
Example: A=1, B=0
A+B = 1 (OR)  |  A·B = 0 (AND)  |  A' = 0 (NOT)

Boolean Algebra Laws

Identity Law

A+0=A   |   A·1=A

Null Law

A+1=1   |   A·0=0

Idempotent Law

A+A=A   |   A·A=A

Complement Law

A+A'=1   |   A·A'=0

Tip: Idempotent = same variable repeat, Null = fixed result, Identity = variable as-is.

De Morgan's Theorem

Do important rules complement nikalne ke liye:

(A+B)' = A'·B'
(A·B)' = A'+B'

Matlab: OR ko AND banao (ya AND ko OR), aur har variable ka complement le lo.

Logic Gates

Logic gates Boolean operations ko physical circuits mein represent karte hain:

  • AND Gate — output 1 tab jab sab input 1 hon
  • OR Gate — output 1 tab jab koi bhi ek input 1 ho
  • NOT Gate — input ko invert karta hai
  • NAND Gate — AND ka opposite
  • NOR Gate — OR ka opposite
  • XOR Gate — output 1 jab inputs different hon

Karnaugh Map (K-Map)

K-Map ek graphical method hai Boolean expressions ko simplify karne ka.

Ye truth table ki jagah grid use karta hai, jisme adjacent cells sirf 1 bit se differ karte hain — isse simplification easy ho jaati hai.

Combinational & Sequential Circuits

Combinational Circuits: Output sirf current input pe depend karta hai (jaise Adder, Multiplexer).

Sequential Circuits: Output current input + past state pe depend karta hai (jaise Flip-Flops, Counters). Inme memory hoti hai.
