 # 🎓 EduLearn - Online Education Website

A simple and clean education website built with **HTML, CSS, and JavaScript**.

## 📌 Features

- Responsive navbar with navigation links
- Hero section with call-to-action button
- Courses section showcasing available courses
- About section
- Footer with contact info

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)

## 📂 Project Structure

education/
├── index.html
├── style.css
└── script.js

## 🚀 How to Run

1. Clone or download this repository
2. Open index.html in any web browser
3. That's it! No installation needed.

## 📸 Sections

- **Home** – Welcome banner with heading
- **Courses** – Digital Logic Design, Web Development, Data Structures
- **About** – Information about the platform
- **Contact** – Footer with email
